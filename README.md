## 🛠️ Built With

- **React 19**
- **Vite**
- **Lucide Icons**
- **Canvas Confetti**
- **Vanilla CSS (Modern Design System)**

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
